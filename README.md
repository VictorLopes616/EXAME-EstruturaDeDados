## Descrição do Projeto

O projeto consiste em uma aplicação desktop desenvolvida em Python com Tkinter, capaz de simular o comportamento de três estruturas de dados fundamentais:

1. **Fila:** Implementação básica de uma fila que permite enfileirar e desenfileirar valores.


- **Funcionalidades:**
  - Inserir elementos no final da fila.
  - Remover elementos do início da fila.

2. **Lista Ligada:** Implementação de uma lista ligada simples para inserção e remoção de elementos no início e fim da lista.


- **Funcionalidades:**
  - Inserir elementos no início e no fim da lista.
  - Remover elementos do início e do fim da lista.


3. **Grafo:** Implementação de um grafo direcionado com capacidade para adicionar vértices, criar arestas com pesos, e realizar buscas em largura (BFS) e profundidade (DFS).



- **Funcionalidades:**
  - Criar vértices clicando no canvas.
  - Adicionar arestas entre vértices especificados.
  - Mover vértices arrastando-os no canvas.
  - Remover vértices e todas as suas conexões.
  - Busca em largura (BFS) e busca em profundidade (DFS) a partir do primeiro vértice adicionado.


## Funcionalidades Principais

1. **Criação de Vértices e Arestas**
   - No grafo, clique no canvas para criar vértices e conectá-los através de arestas.

2. **Manipulação de Elementos**
   - Mova vértices arrastando-os pelo canvas.
   - Remova vértices e suas conexões clicando com o botão direito do mouse.

3. **Operações Específicas**
   - Para a Fila e Lista Ligada, utilize botões específicos para enfileirar, desenfileirar, inserir no início/fim e remover do início/fim.

4. **Buscas em Grafos**
   - Implementadas buscas em largura (BFS) e profundidade (DFS) para explorar grafos a partir de um vértice inicial.
